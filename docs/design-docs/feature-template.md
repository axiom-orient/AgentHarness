# Feature Design Template

## Summary

What is being changed and why?

## User problem

What user pain or workflow issue does this address?

## Non-goals

What are we intentionally not solving now?

## Proposed design

Describe the architecture and flow in plain language.

## Invariants

List rules that must remain true.

## Risks

What can fail or become harder to maintain?

## Verification

How will we know the change works?
