---
name: docs-sync
description: Use when code, behavior, architecture, or plans changed. Detects stale docs and proposes the smallest necessary updates.
---

## Procedure

1. Inspect changed files.
2. Check whether user-facing behavior changed.
3. Check whether architecture or operational behavior changed.
4. Update the relevant spec, plan, or docs file.
5. Summarize what changed and why.

## Targets

- `docs/product-specs/`
- `docs/exec-plans/`
- `ARCHITECTURE.md`
- `PRODUCT_SENSE.md`
- `QUALITY_SCORE.md`
