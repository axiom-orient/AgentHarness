---
name: bug-repro
description: Use when a bug is reported. Reproduce it, collect evidence, define a minimal failing scenario, and verify the fix.
---

## Procedure

1. Rewrite the bug in observable terms.
2. Capture the exact reproduction steps.
3. Gather logs, screenshots, metrics, or traces if available.
4. Reduce to the smallest failing scenario.
5. Implement the fix.
6. Add or update a regression test.
7. Re-run reproduction steps and record the result.

## Output

- repro steps
- expected vs actual behavior
- root cause hypothesis
- verification evidence
