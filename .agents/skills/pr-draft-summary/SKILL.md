---
name: pr-draft-summary
description: Generate a high-signal PR draft that explains change scope, rationale, verification, risk, and follow-up work.
---

## Output format

### Summary
- concise change summary

### Why
- reason for the change

### Verification
- commands run
- tests added or updated

### Risk
- known residual risk
- rollback or fallback note

### Docs
- files updated
